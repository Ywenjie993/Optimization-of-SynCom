# Optimization-of-a-drought-protective-SynCom-for-broad-adaptability-across-wheat-genotypes
Raw plotting data and R scripts for all figures in "Precision microbiome engineering overcomes the incompatibility between wheat genotype and a drought-protective SynCom".
The data/folder provides source data for each figure, and the scripts/ folder contains R scripts that process these data and reproduce the final plots. Scripts were tested on R 4.4.3.
